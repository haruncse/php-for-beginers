### Basics 

1. **What is the primary purpose of software engineering?**
   **Answer:** To create software that meets user requirements efficiently.
   *Explanation:* It ensures the development of reliable, maintainable, and scalable software systems.

2. **Which software development model is characterized by iterative cycles and continuous improvement?**
   **Answer:** Agile model.
   *Explanation:* Agile promotes collaboration, adaptability, and fast feedback through iterative development cycles.

3. **What does the acronym 'OOP' stand for in software engineering?**
   **Answer:** Object-Oriented Programming.
   *Explanation:* A programming paradigm based on the concept of “objects” which contain data and methods.

4. **Which of the following is NOT a principle of software design?**
   **Answer:** Redundancy.
   *Explanation:* Unlike encapsulation, modularity, and scalability, redundancy doesn't enhance design quality.

5. **What is the main advantage of using version control systems like Git?**
   **Answer:** It allows multiple developers to work on the same project simultaneously.
   *Explanation:* Git helps manage collaboration, track changes, and maintain code history effectively.

### Advance 

1. **What is the primary goal of software architecture?**
   - Options:
      1. To define the structure and behavior of software systems
      2. To write code for specific functionalities
      3. To test software for bugs
      4. To manage project timelines
   - Correct Answer: To define the structure and behavior of software systems
   - Explanation: Software architecture focuses on defining the structure and behavior of software systems, ensuring scalability, reliability, and maintainability.

2. **Which design pattern is used to ensure a class has only one instance and provides a global point of access to it?**
   - Options:
      1. Factory Pattern
      2. Singleton Pattern
      3. Observer Pattern
      4. Decorator Pattern
   - Correct Answer: Singleton Pattern
   - Explanation: The Singleton Pattern ensures that a class has only one instance and provides a global point of access to that instance.

3. **What is the purpose of Dependency Injection in software engineering?**
   - Options:
      1. To reduce coupling between components
      2. To increase the speed of execution
      3. To simplify database queries
      4. To enhance user interface design
   - Correct Answer: To reduce coupling between components
   - Explanation: Dependency Injection is a design pattern used to reduce coupling between components by injecting dependencies into a class rather than having the class create them itself.

4. **Which principle of SOLID design emphasizes that a class should have only one reason to change?**
   - Options:
      1. Open/Closed Principle
      2. Single Responsibility Principle
      3. Liskov Substitution Principle
      4. Interface Segregation Principle
   - Correct Answer: Single Responsibility Principle
   - Explanation: The Single Responsibility Principle states that a class should have only one reason to change, ensuring that it has a single responsibility.

5. **What is the main advantage of using microservices architecture?**
   - Options:
      1. It simplifies database management.
      2. It allows independent deployment of services.
      3. It eliminates the need for testing.
      4. It reduces the need for documentation.
   - Correct Answer: It allows independent deployment of services.
   - Explanation: Microservices architecture allows independent deployment of services, enabling scalability and flexibility in software development.

6. **Which algorithm is commonly used for shortest path calculation in graphs?**
   - Options:
      1. Dijkstra's Algorithm
      2. Merge Sort
      3. Binary Search
      4. Prim's Algorithm
   - Correct Answer: Dijkstra's Algorithm
   - Explanation: Dijkstra's Algorithm is commonly used to calculate the shortest path in graphs, especially for weighted graphs.

7. **What is the purpose of the Model-View-Controller (MVC) design pattern?**
   - Options:
      1. To separate concerns in software applications
      2. To optimize database queries
      3. To enhance network security
      4. To simplify debugging
   - Correct Answer: To separate concerns in software applications
   - Explanation: The MVC design pattern separates concerns by dividing an application into three interconnected components: Model, View, and Controller.

8. **Which of the following is a characteristic of RESTful APIs?**
   - Options:
      1. Stateful communication
      2. Use of HTTP methods like GET, POST, PUT, DELETE
      3. Dependence on SOAP protocol
      4. Requirement for XML data format
   - Correct Answer: Use of HTTP methods like GET, POST, PUT, DELETE
   - Explanation: RESTful APIs use HTTP methods like GET, POST, PUT, and DELETE for communication and are stateless, making them lightweight and flexible.

   - Options:
      1. To measure the performance of algorithms
      2. To design user interfaces
      3. To manage project timelines
      4. To debug software applications
   - Correct Answer: To measure the performance of algorithms
   - Explanation: Big O notation is used to measure the performance of algorithms, specifically their time and space complexity.

10. **Which type of testing focuses on verifying the interactions between integrated components?**
   - Options:
      1. Unit Testing
      2. Integration Testing
      3. System Testing
      4. Acceptance Testing
   - Correct Answer: Integration Testing
   - Explanation: Integration Testing focuses on verifying the interactions between integrated components to ensure they work together as expected.

11. **What is the primary purpose of Continuous Integration (CI) in software development?**
   - Options:
      1. To automate the deployment process
      2. To merge code changes frequently and test them automatically
      3. To write code faster
      4. To eliminate the need for manual testing
   - Correct Answer: To merge code changes frequently and test them automatically
   - Explanation: Continuous Integration (CI) involves merging code changes frequently and testing them automatically to detect issues early in the development process.

12. **Which database normalization form eliminates duplicate columns and ensures that each column contains atomic values?**
   - Options:
      1. First Normal Form (1NF)
      2. Second Normal Form (2NF)
      3. Third Normal Form (3NF)
      4. Boyce-Codd Normal Form (BCNF)
   - Correct Answer: First Normal Form (1NF)
   - Explanation: First Normal Form (1NF) eliminates duplicate columns and ensures that each column contains atomic values, making the database more organized.

15. **What is the purpose of the 'DRY' principle in software engineering?**
   - Options:
      1. To avoid code duplication
      2. To enhance user interface design
      3. To simplify debugging
      4. To optimize database queries
   - Correct Answer: To avoid code duplication
   - Explanation: The 'DRY' (Don't Repeat Yourself) principle aims to avoid code duplication, making the codebase more maintainable and efficient.
