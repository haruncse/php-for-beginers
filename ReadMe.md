### Basic PHP Lab Questions
1. **Introduction to PHP**
   - Write a script to display "Hello, World!" on the webpage.
   - Create a script to demonstrate the use of variables and constants in PHP.

2. **Conditional Statements**
   - Write a program to check whether a given number is odd or even.
   - Create a script to find the largest number among three given numbers.

3. **Loops**
   - Use a `for` loop to generate and print the multiplication table for a given number.
   - Create a program to calculate the sum of numbers from 1 to N using a `while` loop.

4. **Functions**
   - Write a user-defined function to calculate the factorial of a number.
   - Create a function to reverse a given string.

5. **Arrays**
   - Write a PHP script to display all elements of an associative array.
   - Create a program to sort an array in ascending order.

6. **Forms**
   - Design a form for user input and write PHP code to handle and display the submitted data.
   - Create a login form and validate credentials using PHP.

7. **File Handling**
   - Write a program to create, write, and read content from a text file in PHP.
   - Develop a script to append data to an existing file.

8. **Database Integration (Basic SQL)**
   - Connect a PHP script to a MySQL database and perform a `SELECT` query to display table data.
   - Write a program to insert form data into a database table.

### Basic PHP Lab Questions (Extended)

#### 9. String Handling
- Write a PHP script to count the number of vowels in a given string.
- Create a program to check if a given string is a palindrome.
- Write a script to replace a specific word in a string with another word.

#### 10. Sessions and Cookies
- Create a program to demonstrate the use of sessions for storing user data.
- Write a PHP script to create, retrieve, and delete cookies.

#### 11. PHP and JSON
- Write a program to encode an associative array into a JSON object and decode it back.
- Create a script to read data from a JSON file and display it on a webpage.

#### 12. Error Handling
- Write a PHP script to demonstrate the use of `try`, `catch`, and `finally` for exception handling.
- Develop a program to handle file upload errors.

#### 13. Date and Time
- Create a PHP program to display the current date and time in different formats.
- Write a script to calculate the difference between two dates.

#### 14. Advanced Database Integration
- Write a program to update data in a MySQL table using PHP.
- Create a PHP script to delete records from a database table based on a condition.

#### 15. Object-Oriented Programming (OOP)
- Write a PHP class to represent a rectangle and include methods to calculate its area and perimeter.
- Create a program demonstrating inheritance in PHP using a "Vehicle" superclass and a "Car" subclass.

#### 16. Regular Expressions
- Write a program to validate an email address using regular expressions.
- Develop a script to find and replace patterns in a given string.

#### 17. File Upload
- Create a form to upload a file and write a PHP script to handle and store the uploaded file.
- Write a program to restrict file uploads based on file size and type.

#### 18. PHP and XML
- Write a PHP script to read data from an XML file and display it.
- Create a program to generate an XML file from a PHP array.

#### 19. PHP Email
- Write a script to send an email using PHP's `mail()` function.
- Create a program to send HTML-formatted emails with attachments.

#### 20. PHP Security
- Write a script to sanitize and validate user input to prevent SQL injection.
- Create a login system with hashed passwords using `password_hash()` and `password_verify()`.
